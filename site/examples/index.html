year / month / week on claude

Live-rendered SVG posters from a real claude-rpc aggregate. Each card is ~880×540, monospace-heavy, designed to be screenshotted and shared. GitHub READMEs render SVG images as-is, so there's no PNG step for a README; Discord doesn't embed SVG, so for chat, post a screenshot. Below: four ranges, all from the same lifetime dataset.

year on claude raw svg ↗
claude-rpc card --range year --out year.svg
month on claude raw svg ↗
claude-rpc card --range month --out month.svg
week on claude raw svg ↗
claude-rpc card --range week --out week.svg
all-time on claude raw svg ↗
claude-rpc card --range all --out all-time.svg

always-current cards for your README

The posters above are files: render one with claude-rpc card and commit it. For cards that keep themselves up to date, publish a profile (claude-rpc profile on) and the community worker serves a stats card, a profile card and badges at public URLs anyone can load. claude-rpc readme prints the markdown with your handle filled in. 

https://claude-rpc-totals.claude-rpc.workers.dev/stats/your-handle.svg
https://claude-rpc-totals.claude-rpc.workers.dev/card/your-handle.svg
https://claude-rpc-totals.claude-rpc.workers.dev/badge/your-handle.svg?metric=hours

claude-rpc serve also re-renders these four posters on every request at http://127.0.0.1:47474/api/card.svg?range=year (or month, week, all), but that address only exists on your own machine: handy for a preview, useless in a README.
